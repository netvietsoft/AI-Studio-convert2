## 2. KẾT QUẢ TRIỂN KHAI CỤ THỂ

### 2.1 Cập Nhật Lõi C++ Core Engine (`hair_pipeline_v2.cpp`)
- **Vị trí can thiệp:** `lib-core-graphics/src/main/cpp/src/hair/hair_pipeline_v2.cpp`
- **Loại bỏ triệt để:** Bỏ hoàn toàn hình bầu dục elip nhân tạo (`dx*dx + dy*dy <= 1.0`) và logic threshold YCrCb gây lệch màu trên các dáng đầu nghiêng hoặc tóc xoăn xù.
- **Triển khai Mask Exclusion Clamping:**
  $$\text{blackvalue} = 1.0 - \text{excl}$$
  $$\text{val} = \min(\text{raw\_hair}, \text{blackvalue})$$
  $$\text{if } \text{excl} \ge 0.95 \implies \text{val} = 0.0$$
  kẹp triệt để mặt nạ tóc theo vùng cấm ngữ nghĩa (da mặt, trán, cổ áo, vành tai).
- **Triển khai Pegtop SoftLight Photometric Kernel:**
  Thay thế phép thế màu tuyến tính OKLab bằng công thức hòa trộn quang học Pegtop SoftLight:
  $$\text{Nếu } B \le 0.5: \quad C = 2AB + A^2(1 - 2B)$$
  $$\text{Nếu } B > 0.5: \quad C = 2A(1 - B) + \sqrt{A}(2B - 1)$$
  bảo vệ độ phản quang sợi tóc ($\lim_{A \to 1} C = 1$) và chiều sâu chân tóc ($\lim_{A \to 0} C = 0$).
