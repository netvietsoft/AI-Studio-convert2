# Executive Summary – Meitu Hair‑Color Competitor Analysis (AGY_001)

## High‑level Pipeline (observed)
- **Segmentation**: Meitu uses on‑device AI models (`MTAiEngine` / `MTARDenseHairModel`, etc.) to produce a hair mask. The mask is refined with shader `MTFilter_HairMaskMix.fs` that subtracts face/body masks to prevent forehead leakage.  
- **Material / LUT**: `MTIKHairFilter` constructs a material descriptor (LUT path, texture, blend order) and invokes native methods such as `nSetDyeHairMaterialInfo` and `nDoDydHairRender`. The actual color transformation is performed in native code (missing libs `libmtImageKit.so`, `libMTAiInterface.so`).  
- **Blending**: Soft‑light and luminosity shaders (e.g., `PsSoftLightr`, `PsFilterColor`) blend the dyed result back onto the original image, preserving highlights and texture.

## Missing Native Components
- Critical native libraries **not present** in the extracted XAPK:
  - `libmtImageKit.so`
  - `libMTAiInterface.so`
  - `libvlai.so`
- Without these libs we cannot inspect the exact dye algorithm (color space, LUT handling, blend parameters).

## Mapping Our Failure Modes
| Failure Mode | Observed Meitu Mechanism | Confidence | Recommendation |
|--------------|--------------------------|------------|----------------|
| Forehead leak | Mask subtraction using `MTFilter_HairMaskMix.fs` (hair‑mask ∧ ¬face‑mask) | 0.92 | Implement similar mask subtraction step after hair segmentation. |
| Flat painted look | Lack of soft‑light/LUT blending; Meitu uses LUT + `PsSoftLightr` shader for tonal realism. | 0.88 | Add LUT‑based color map and soft‑light blend shader. |
| Shoulder/cloth spill | No full‑body segmentation; Meitu combines hair mask with body‑mask to mask out clothes. | 0.81 | Incorporate body‑segmentation mask (BiSeNet‑19) to restrict dye region. |

## Actionable Recommendations
1. **Acquire full XAPK** containing the missing `.so` libraries to reverse‑engineer the exact dye routine.  
2. **Implement mask subtraction**: after hair mask generation, load the face mask (`MTFilter_FaceMask.fs`) and perform pixel‑wise `hairMask = hairMask & !faceMask`.  
3. **Add LUT‑based color material**: replicate `MTIKHairFilter` JSON schema, load a hair‑color LUT (e.g., `hair_lut.png`), and feed it to a soft‑light shader.  
4. **Integrate body segmentation** (BiSeNet‑19) to generate a clothing mask and exclude it from the dye effect.  
5. **Validate** using the existing test suite and visual QA (target ≤ 5 % leakage, ≥ 90 % naturalness).
