1.2 CURRENT HAIR AI

Model:
BiSeNet 19-Class Face Parser.

Runtime:
NCNN.

Input:
512 x 512 x 3 RGB.

Output:
512 x 512 x 19.

Hair:
Class 17.

Current extraction:
19-class logits

-> class 17
-> binary hair mask.

BiSeNet remains useful as coarse semantic anchor.

It is NOT sufficient by itself for fine hair alpha matting.

1.3 CURRENT HAIR MASK / MATTING

Current implementation:
BiSeNet binary mask
-> conditional morphological propagation
-> protection barriers
-> luminance-based feather
-> bilinear upscale.

Current system DOES NOT contain an industrial-grade dedicated hair matting
solver according to the latest audit.

Do not describe the current output as "true physical sub-pixel hair matte"
merely because alpha values become continuous after interpolation/feathering.

1.4 CURRENT HAIRLINE / FLYAWAY

Current hairline:
primarily determined by BiSeNet Hair vs Skin boundary and rule-based protection.

Current flyaway recovery:
conditional propagation based partly on luminance/background rules.

Known issues:
- forehead hairline can appear too sharp;
- very thin flyaways can be cut;
- boundary quality depends on coarse semantic segmentation.

Current hair_strand_dye.cpp includes:

Current tri-band approximation:

This is 2D image-frequency processing.

It is NOT:

2. CURRENT ROOT CAUSE
========================================================================

Primary visual defect:
Hair looks partially like a pink color coating rather than naturally recolored hair.

Confirmed/strongly supported engineering causes:

1. Coarse semantic hair mask.
2. No dedicated high-quality hair matting pipeline.
3. No Hair Orientation/Flow.
4. No orientation-aware strand texture processing.
5. Shared Rose Gold chromaticity over most of hair.
6. Simplified luminance lift.
7. Simplified isotropic specular.
8. No anatomical/root-body-tip color variation.
9. Linear alpha composition remains a major final color-composition mechanism.
10. Very thin flyaways/hairline are not robustly represented.

Terminology correction:

DO NOT call current:
melaninLift

"physical melanin bleaching".

Correct name:
Luminance Lift Heuristic
or
Melanin-inspired Lift Approximation.

DO NOT claim RGB image measures true pheomelanin/eumelanin concentration.

Correct term:
Warm Undertone Appearance Estimate
or
Warm Bleach Undertone Simulation.

DO NOT promise:
"Flawless 100% Bit-Accurate Salon Output".

Correct target:
"Validated High-Quality Hair Recolor Output".

OBJECTIVE:
Preserve strand/curl texture instead of processing hair as an isotropic 2D surface.

struct HairStructure {
    ImageFloat lowFrequency;
    ImageFloat midFrequency;
    ImageFloat highFrequency;
    ImageFloat ridgeResponse;
    ImageFloat creviceResponse;

Candidates:
- directional bilateral;
- anisotropic smoothing;
- guided filter;
- Gabor response;
- flow-guided sampling.

Rules:

Dark crevices must not be lifted to the same luminance as exposed strands.

High-frequency texture must not simply be multiplied by a static dye RGB.

P2 PASS:

[ ] More original strand detail than baseline.
[ ] Curl crevices remain deep.
[ ] No artificial sharpening halo.
[ ] No background texture enters hair.
[ ] Hairline remains stable.
