13. GEOMETRY TRANSFORM CONTRACT
======================================================================

For Letterbox:

scale = min(512/W, 512/H)

newW = round(W * scale)
newH = round(H * scale)

padX = (512 - newW) / 2
padY = (512 - newH) / 2

Store:

struct SemanticTransform {
    float scale;
    int resizedWidth;
    int resizedHeight;
    int padLeft;
    int padTop;
    int inputWidth;
    int inputHeight;
};

Inverse mapping must be deterministic.

No semantic coordinate may be mapped by guessed scale factors.
