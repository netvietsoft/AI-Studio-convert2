4. FIX F1 — LOW-CONTRAST DARK HAIR
======================================================================
Vấn đề: Hair Color ≈ Background Color nên color distance không đủ.

Tạo:
LowContrastHairResolver.h/.cpp

struct LowContrastHairEvidence {
    float seedSimilarity;
    float connectivity;
    float textureSimilarity;
    float edgeContinuity;
    float spatialPrior;
    float semanticConfidence;
    float backgroundPenalty;
    float confidence;
};

struct LowContrastHairResult {
    ImageFloat probability;
    ImageFloat confidence;
};

4.1 Connectivity
Candidate được mở rộng khi:
- connected tới confirmed hair core;
- propagation path nhất quán;
- không xuyên protected semantic;
- propagation distance hợp lý;
- confidence không sụp.
CẤM unrestricted flood-fill.

4.2 Texture similarity
Có thể dùng lightweight:
- gradient magnitude;
- gradient histogram;
- local variance;
- Laplacian energy;
- small LBP-like descriptor nếu có bằng chứng;
- multi-scale luminance residual hiện có.
Không làm Hair Orientation ở đây.

4.3 Edge continuity
Không cho propagation vượt strong incompatible boundary.

4.4 Spatial prior
Face/head geometry chỉ là weak prior.
Tóc có thể vượt skull, phủ vai/tai và chạm border.
Không tạo anatomical cage cứng.

4.5 Background penalty
Disconnected + large background + no semantic/texture evidence
=> tăng background penalty.

Concept:
P_dark_hair =
 w_seed*SeedSimilarity +
 w_connectivity*Connectivity +
 w_texture*TextureSimilarity +
 w_edge*EdgeContinuity +
 w_spatial*SpatialPrior +
 w_semantic*SemanticConfidence -
 w_background*BackgroundPenalty;

Weights:
- document;
- global;
- không tune theo filename;
- có sensitivity report.

Nếu evidence thấp:
preserve confirmed core + conservative fallback.
Không fabricate hair.

F1 HARD GATE:
sample_05 phải vượt project Hair Core threshold mà không làm tăng đáng kể
dark-background leakage.
