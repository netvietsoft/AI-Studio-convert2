VIDEO EDITOR / VIDEOCORE C++ — REPOSITORY LIST
===================================================

Mục tiêu:
Chưng cất các dự án open-source thành VideoCore C++ riêng cho Android/iOS,
theo kiến trúc NLE + GPU + AI + Beauty, không fork nguyên một editor.

1. FFmpeg
https://github.com/FFmpeg/FFmpeg
Vai trò: Decode/encode, mux/demux, codec, audio/video filter, resample, scale.
Module đích: MediaCore, DecodeCore, EncodeCore, ExportCore.

2. OpenTimelineIO
https://github.com/AcademySoftwareFoundation/OpenTimelineIO
Vai trò: Timeline data model, Clip, Track, Transition, Marker, timing.
Module đích: TimelineCore.

3. libopenshot
https://github.com/OpenShot/libopenshot
Vai trò: C++ video editing library; timeline, effects, keyframe, compositing,
time mapping, audio.
Module đích: Tham khảo kiến trúc NLE C++.

4. Shotcut
https://github.com/mltframework/shotcut
Vai trò: NLE/editor architecture.
Module đích: Tham khảo UI-editor workflow, timeline/editor integration.

5. MLT
https://github.com/mltframework/mlt
Vai trò: Multimedia framework cho NLE.
Module đích: Tham khảo media graph, producer/filter/consumer architecture.

6. libplacebo
https://github.com/haasn/libplacebo
Vai trò: GPU image/video processing, shaders, color/render pipeline.
Module đích: GPUCore / RenderCore reference.

7. frei0r
https://github.com/dyne/frei0r
Vai trò: Video effects/plugin API và thư viện filter.
Module đích: EffectPlugin architecture.

8. GPAC
https://github.com/gpac/gpac
Vai trò: MP4, media packaging, streaming.
Module đích: Container/Packaging/Export.

9. OpenCV
https://github.com/opencv/opencv
Vai trò: Optical flow, tracking, geometry, image processing.
Module đích: TrackingCore / VisionUtility.

10. OpenColorIO
https://github.com/AcademySoftwareFoundation/OpenColorIO
Vai trò: Color management.
Module đích: ColorManagementCore.

11. whisper.cpp
https://github.com/ggerganov/whisper.cpp
Vai trò: Speech-to-text C/C++.
Module đích: AutoCaptionCore.

12. Rubber Band
https://github.com/breakfastquay/rubberband
Vai trò: Audio time stretching và pitch shifting.
Module đích: AudioSpeed/Pitch Engine.
Lưu ý: kiểm tra commercial licensing.

13. RIFE NCNN Vulkan
https://github.com/nihui/rife-ncnn-vulkan
Vai trò: AI frame interpolation.
Module đích: AISlowMotionCore.

14. Real-ESRGAN
https://github.com/xinntao/Real-ESRGAN
Vai trò: AI super-resolution / restoration.
Module đích: VideoEnhanceCore.

15. Real-ESRGAN NCNN Vulkan
https://github.com/xinntao/Real-ESRGAN-ncnn-vulkan
Vai trò: NCNN/Vulkan deployment cho enhancement.
Module đích: Mobile AI Enhance.

16. Robust Video Matting
https://github.com/PeterL1n/RobustVideoMatting
Vai trò: Temporal human matting.
Module đích: BackgroundRemovalCore.

17. BackgroundMattingV2
https://github.com/PeterL1n/BackgroundMattingV2
Vai trò: High-resolution human/background matting.
Module đích: MattingCore.

18. MediaPipe
https://github.com/google-ai-edge/mediapipe
Vai trò: Face/body/hand landmark và tracking pipelines.
Module đích: HumanTracking reference.

19. NCNN

Vai trò: C++ mobile inference + Vulkan.
Module đích: AIRuntime.

20. OpenSubdiv

Module đích: GenerativeCore research/reference.

7. Preview và Export dùng cùng effect semantics.
8. Project phải save/reload chính xác.
9. Undo/Redo dùng command/history model.
10. Mọi thao tác phải non-destructive.
