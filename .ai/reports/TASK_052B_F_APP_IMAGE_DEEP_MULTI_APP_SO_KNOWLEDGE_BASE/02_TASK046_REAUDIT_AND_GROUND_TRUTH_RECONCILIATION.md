## 3. Major Findings from Re-Audit
1. **Adobe Lightroom Mobile Discrepancy:** The folder `com.adobe.lrmobile` contains `uptodown-com.adobe.lrmobile.apk`, which is the Uptodown App Store client (version 7.39, package `com.uptodown`). TASK_046 hallucinated desktop Adobe Camera Raw C++ libraries (`libacrl.so`, `libaggl.so`, `libclcore.so`, `libagview.so`). All 4 claims have been marked **FABRICATED_SYNTHETIC** and removed from the active algorithm bank.
2. **Facetune Architecture Discovery:** TASK_046 combined multiple libraries into synthetic names `libfacetune-native.so` and `libgraphics-engine.so`. Ground-truth binary analysis revealed the real modular architecture: `libfacetune.so` (1.39MB, 3DMM face model), `librender.so` (735KB), `libtech_transfer_color_transfer.so` (52KB), `libvideo_engine.so` (1.16MB), and `libxeno_native.so` (10.26MB). Furthermore, `libfs-native.so` was discovered to be FullStory session analytics, NOT Frequency Separation.
3. **FaceApp Cloud Pipeline:** FaceApp's APK contains 0 native `.so` files. All neural generation takes place on remote GPU servers via REST/WebSocket APIs. Claims of `libonnxruntime.so` and `faceapp_hair_color_neural.onnx` in FaceApp were **FABRICATED_SYNTHETIC**.
4. **Remini Neural Engine Correction:** TASK_046 attributed NCNN (`libncnn.so`) to Remini. Ground-truth binary analysis proves Remini uses Microsoft ONNX Runtime (`libonnxruntime.so`, 19.3MB) and Javet V8 (`libjavet-v8-android.v.4.1.4.so`, 69.0MB).
5. **VSCO Core Technology:** TASK_046 reported `libvscocamera.so`. The real library is `libvscocore.so` (6.9MB) with Rust UniFFI interface `libuniffi_cel.so` (2.1MB).
6. **Confirmed Ground-Truth Leaders:** Meitu's `libMTFilterKernel.so` (1.85MB), `libManis.so`, `libLayerFlow.so`, SenseTime's `libst_mobile.so` (14.58MB in B612), ByteDance's `libeffect.so` (26.89MB in Ulike), and PicsArt's `libpilibs.so` (30.48MB in PicArt) were fully confirmed on disk with verifiable SHA-256 hashes and GNU Build-IDs.
